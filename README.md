## Run Locally

Clone the repository:

```bash
git clone https://github.com/mayurtambat01/mayur-portfolio.git
```

Open the project directory:

```bash
cd mayur-portfolio
```

Start the local development server:

```bash
python tools/serve.py 5173
```

Then open:

```text
http://127.0.0.1:5173
```
